## 1. Problem Overview

The Community Lost & Found Matching Network is a community-based system designed to help users recover lost items by matching Lost Item and Found Item reports.

The system extracts visual and text-based item tags and performs matching based on item category, colour, tags and geographical proximity. Potential claimants are required to verify ownership through private security questions before relevant handover contact details are revealed.

---

## 2. Actors

The system has two primary actors:

- **Finder / Owner** — Creates Lost/Found reports, views potential matches, receives notifications and claims found items.
- **Community Admin** — Reviews and manages reports and handles disputed claims.

## 4. Core Functionality

The major functionality of the system includes:

1. Registering Lost and Found Item reports.
2. Extracting item tags from text and images.
3. Matching Lost and Found reports using item characteristics and geographical proximity.
4. Sending notifications for potential matches.
5. Verifying ownership using private questions.
6. Revealing handover contact details after successful verification.
7. Allowing Community Admins to manage reports and disputed claims.
